Mamão-formosa

Carica papaya · grupo Formosa

Mamão-formosa é um grupo comercial de mamões geralmente maiores que os do grupo Solo. O mamoeiro tem caule pouco ramificado e folhas grandes concentradas na parte superior; apesar do porte, botanicamente não é uma árvore lenhosa. A imagem é ilustrativa de Carica papaya e não identifica uma cultivar Formosa específica.
